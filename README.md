# ASCII Fire — живые обои для GNOME

Расширение GNOME Shell (Wayland и X11, GNOME 45+ ESM, проверено на GNOME 50), которое рисует на рабочем столе огонь из символов моноширинного шрифта.

Сценарий анимации:
1. На тёмном фоне стоит тусклая незажжённая свеча.
2. Появляется спичка, её огонёк подплывает к фитилю и зажигает его.
3. Свеча горит, пламя постепенно разрастается.
4. Свеча падает, при ударе вспыхивает купол огня и по экрану расходится волна.
5. Огонь растекается в полосу на всю ширину экрана и горит бесконечно, над ней летят искры.

## Установка

```bash
./install.sh
```

Скрипт копирует расширение в `~/.local/share/gnome-shell/extensions/ascii-fire@local/`, ставит однотонный фон `#16161d` и включает расширение. На Wayland после первой установки нужно выйти из сеанса и войти снова.

## Настройки

Константы наверху `ascii-fire@local/extension.js`:

| Константа | Значение |
|---|---|
| `TRIGGER_MODE` | `'hover'` — навести мышь на центр экрана, `'click'` — клик ЛКМ в центре, `'always'` — сразу |
| `HOVER_DELAY_MS`, `ZONE_RX`, `ZONE_RY` | задержка и размер эллиптической зоны в центре |
| `FPS`, `CELL_W`, `CELL_H`, `FONT_SIZE` | частота кадров и размер ячейки |
| `BG_COLOR` | цвет фона |
| `SIM_OPTIONS` | переопределение `DEFAULTS` из `fire.js` (длительность этапов, размеры свечи, высота пламени) |

Анимация ставится на паузу, когда рабочий стол закрыт развёрнутым или полноэкранным окном, а также в обзоре.

## Устройство

- `ascii-fire@local/fire.js` — симуляция (алгоритм Doom fire на сетке символов, свеча, искры). Без импортов GNOME.
- `ascii-fire@local/extension.js` — `St.DrawingArea` в `Main.layoutManager._backgroundGroup` над обоями, отрисовка через Cairo с группировкой по цвету.

Проверить симуляцию в консоли:

```bash
node test_fire.mjs   # или: gjs -m test_fire.mjs
```

## Удаление

```bash
gnome-extensions disable ascii-fire@local
rm -rf ~/.local/share/gnome-shell/extensions/ascii-fire@local
```
